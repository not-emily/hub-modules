{% elsif audit.deep_dive %}

How to read this report. The scores below come from Lighthouse, which runs the axe accessibility engine. Automated tooling reliably catches around a third of WCAG success criteria — things a machine can see, like missing alt attributes and insufficient colour contrast.

It cannot judge whether alt text is meaningful, whether focus order makes sense, or whether a component is operable by keyboard. Those are covered in the manual review section on each page. A score of 100 is not a statement of compliance.
