{%- comment -%} External-link glyph. Purely decorative: aria-hidden, so every link using it must get its accessible name from visible text or an .sr-only span. focusable="false" keeps older Edge and IE from putting the SVG itself in the tab order. Uses currentColor rather than a fixed fill so it tracks the link colour on hover and focus, and reads correctly in both light and dark themes. It carries no id — this renders once per table row, and a repeated id would be invalid markup and a duplicate-identifier defect of exactly the kind this report flags. {%- endcomment -%}
